# CrossHair - Настраиваемый прицел для экрана

**CrossHair** — это простое и удобное приложение на C#, которое отображает настраиваемый прицел поверх всех окон на экране. Приложение позволяет гибко настраивать внешний вид прицела, включая размер, цвет центральной точки и рамки. Идеально подходит для геймеров, стримеров, кто хочет иметь кастомизированный прицел на экране.

## Основные функции

- **Отображение прицела поверх всех окон**: Прицел всегда остается поверх других приложений.
- **Настройка размера**: Изменение размера прицела под ваши нужды.
- **Настройка цвета**:
  - Изменение цвета центральной точки.
  - Изменение цвета рамки прицела.
- **Минималистичный интерфейс**: Простота в использовании и быстрая настройка.

---

## Как использовать

1. Скачайте последнюю версию приложения из раздела [Releases](https://github.com/tntmain/CrossHair/releases).
2. Запустите `Cross.exe`.
3. Настройте прицел:
   - Измените размер с помощью слайдера или текстового поля.
   - Выберите цвет центральной точки и рамки.
4. Закройте настройки — прицел останется на экране.

## Установка и сборка из исходного кода
